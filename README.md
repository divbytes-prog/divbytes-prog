## 🧠 MoodTrip

A **mood-aware place recommendation system** that combines live place discovery with machine-learning ranking, explainability, contextual scoring, and feedback learning.

### ✨ Highlights

- 12 mood profiles
- 22 ranking features
- Distilled neural ranker
- Random Forest + XGBoost + MLP teacher ensemble
- Integrated Gradients-style explanations
- Contextual bandit scoring
- Group mood blending
- Anonymous feedback pipeline
- Live nearby-place discovery with maps

**Tech Stack**  
`React` `Vite` `JavaScript` `Python` `scikit-learn` `XGBoost` `Supabase` `Leaflet` `Vercel`
